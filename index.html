Khung Nền Tảng - Chặng 1 Đã Sẵn Sàng

Hệ thống lõi dành cho sinh viên Cơ điện tử (Cơ học, Vật lý) đã được khởi tạo. Các module đã nạp vào bộ nhớ:

  • Cấu hình & Bảo mật: Lưu trữ độc lập trong localStorage, tự động escape dữ liệu đầu ra.
  • Adapter Đa Mô Hình (`callLLM`): Hỗ trợ Google Gemini, Anthropic Claude, OpenAI và OpenAI-Compatible.
  • Điều tiết lượt gọi (Rate Limiter): Hàng đợi cửa sổ trượt 60 giây, tự động thử lại khi gặp lỗi 429 hoặc JSON bị hỏng.
  • Lưu trữ GitHub REST API & IndexedDB Cache: Xử lý UTF-8 tiếng Việt hoàn chỉnh, phát hiện xung đột SHA.
